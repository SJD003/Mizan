# مَدى

مَدى نموذج أولي تجريبي لواجهة محادثات عربية وخادم API مبني على Node.js، من دون أطر عمل أو تبعيات تشغيل خارجية.

## التشغيل محليًا

- يتطلب Node.js 22 أو أحدث وnpm.
- شغّل `npm start` لبدء الخادم على `http://127.0.0.1:3000`.
- شغّل `npm test` لتنفيذ الاختبارات.

يقبل الخادم ضبط `MADA_HOST` و`PORT`. يرفض ربط واجهة غير محلية عبر HTTP خارج GitHub Codespaces؛ للوصول خارج الجهاز المحلي استخدم HTTPS مع إعداد `MADA_TLS_CERT` و`MADA_TLS_KEY`.

## GitHub Codespaces

يضبط `.devcontainer/devcontainer.json` بيئة Node.js 22، وينفذ `npm test` بعد إنشاء الحاوية، ثم يبدأ `npm start` عند بدء الحاوية. يُمرّر المنفذ 3000 بوضوحية **private**. يعمل التطبيق خلف proxy الخاص بـ Codespaces، ولا يقبل الخادم هناك إلا الطلبات التي تحمل `X-Forwarded-Proto: https` و`X-Forwarded-Host` صالحين؛ تُستخدم هذه القيم لضبط same-origin ووسم cookies الآمنة ورؤوس HTTPS. لا يثق الخادم بهذه الرؤوس خارج Codespaces.

## التخزين والحدود

تُحفظ الحسابات والمحادثات والرسائل محليًا في `data/mada.json`، وتُحفظ المرفقات في `data/uploads/`. غيّر المجلد باستخدام `MADA_DATA_DIR`. المجلد مستثنى من Git. يدعم الخادم كاتبًا واحدًا لكل مجلد بيانات، وتُدار الجلسات في ذاكرة الخادم؛ لذلك يلزم تسجيل الدخول مجددًا بعد إعادة التشغيل.

### إعادة تعيين كلمة المرور

إعادة التعيين عبر البريد تتطلب إعداد Resend:

- `MADA_RESEND_API_KEY`: مفتاح Resend.
- `MADA_EMAIL_FROM`: عنوان مرسل موثّق لدى Resend.
- `MADA_PUBLIC_URL`: عنوان HTTPS عام للتطبيق، مثل `https://mada.example.com`، بلا مسار أو query أو fragment.

1. أنشئ مفتاح API في Resend وتحقق من عنوان المرسل لدى المزود.
2. خزّن المتغيرات الثلاثة في مدير أسرار بيئة التشغيل، ولا تحفظ المفتاح في المستودع.
3. أعد تشغيل الخادم وتحقق من وصول رسالة الاستعادة إلى صندوق اختبار تملكه.

يرسل الخادم عبر `fetch` المدمج في Node.js. يعيد طلب الاستعادة ردًا عامًا لا يكشف وجود الحساب؛ الرمز عشوائي أحادي الاستخدام وتنتهي صلاحيته بعد 30 دقيقة، ولا يُحفظ إلا hash الخاص به. يتطلب تغيير كلمة المرور CSRF وكلمة مرور بطول 12–128 حرفًا، ويبطل جلسات الحساب السابقة.

في التشغيل المحلي فقط، إذا لم يُضبط أي من متغيرات البريد وكان `NODE_ENV` ليس `production`، و`CODESPACES` ليس `true`، والخادم مربوطًا بعنوان loopback، يطبع الخادم رابط الاستعادة إلى stdout مع تنبيه بأنه للرصد المحلي فقط. لا تعرضه للمستخدمين ولا تشاركه. في الإنتاج وCodespaces، يؤدي غياب أي إعداد مطلوب إلى خطأ إعداد واضح؛ لا يُنشأ رمز ولا رابط استعادة. فشل مزود البريد لا يترك رمزًا صالحًا في المخزن.

**هذا تطبيق تجريبي غير جاهز للإنتاج. لا تستخدم فيه بيانات حقيقية أو حساسة، ولا ترفَع أو تُدخل معلومات شخصية أو كلمات مرور مستخدمة في خدمات أخرى.** لا يتوفر تشفير طرفي أو استعادة حساب آمنة تشغيليًا دون إعداد مزود البريد، أو تخزين موزع، أو تشغيل متعدد النسخ. بيانات المخزن محلية وليست خدمة تخزين آمنة أو احتياطية.
